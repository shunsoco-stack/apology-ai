## ポートフォリオ用紹介文

### 謝罪AI — 考え抜いた結果、すみません。

どんな相談を入力しても、最終的に謝ることしかできないAI風のジョークアプリです。「状況を分析中」「言い訳を削除中」と本格的な処理を思わせた後、返ってくるのは、驚くほどシンプルな謝罪。使い込むほど役に立たなさが伝わる、そのギャップを体験として設計しました。

通常・丁寧・超高性能の3モードに加え、コピー、共有、音声読み上げ、端末内の謝罪履歴、累計・本日の謝罪回数を実装。モバイルファーストの画面、ダークモード、キーボード操作、動きを抑える設定、ホーム画面への追加に対応しています。

Next.js App Router / TypeScript / Tailwind CSSで制作。**生成AI API不使用**で、オリジナルの固定テンプレートとブラウザの機能だけで動作し、AI APIキーや生成料金は必要ありません。入力内容はサーバーへ送らず、端末内だけで処理します。Vercel Analyticsのイベントに、入力文や履歴の本文は含めません。

※実際のトラブル・法的問題・重大な謝罪には使用しないでください。個人情報や機密情報の入力もお控えください。

## Tsukutta用紹介文

### すごく考えて、ただ謝る。「謝罪AI」をつくりました。

相談を書く。相手と深刻度を選ぶ。AIに考えてもらう。

「状況を分析中」
「責任の所在を確認中」
「言い訳を削除中」
「謝罪を生成中」

そして出てくる答えは——「すみませんでした」。

超高性能モードにすると「このたびは誠に申し訳ございませんでした」。性能の差は、主に丁寧さです。

本格的なAIサービスのような画面と、あまりに単純な返答のギャップを楽しむジョークアプリです。謝罪のコピー・共有・読み上げ、声と速度の選択、謝罪回数のカウント、端末内の履歴に対応。スマートフォンでも使え、ホーム画面に追加できます。

**生成AI API不使用。** 事前に用意したオリジナルの謝罪テンプレートを使い、入力内容はサーバーへ送信しません。AI APIキーも生成料金も不要です。

実際のトラブルや重大な謝罪のためのツールではありません。個人情報・機密情報は入力せず、肩の力を抜いてお楽しみください。
