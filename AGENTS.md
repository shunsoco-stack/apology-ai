## Project principles

- This is an explicitly labeled joke app. Never add a generative AI API or API key.
- User input must stay in memory on the user's device. Never send or persist it.
- Persist only validated apology templates, choices, timestamps, and counters.
- Analytics must contain only allowlisted event names and mode, never user text.
- Keep keyboard, reduced motion, dark mode, and mobile behavior usable.
- Before publishing run lint, typecheck, test, build, and secret-scan.
